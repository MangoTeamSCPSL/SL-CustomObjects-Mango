# SL-CustomObjects — Mango Edition

Unity-проект для создания схематиков ProjectMER. В Mango Edition игровые объекты
можно расставлять и настраивать прямо в редакторе, без ручной правки JSON и
последующего размещения через Remote Admin.

Проект основан на
[Michal78900/SL-CustomObjects](https://github.com/Michal78900/SL-CustomObjects).

## Что добавлено

Все новые объекты находятся в меню `GameObject → MER Objects`.

| Объект | Доступные варианты | Настройки |
| --- | --- | --- |
| Дверь | LCZ, HCZ, EZ, Bulkdoor, Gate | Доступ, начальное состояние, блокировка |
| TextToy | Текстовый экран | Текст и размер области |
| InteractableToy | Box, Sphere, Capsule | Время взаимодействия и блокировка |
| WaypointToy | Область навигации | Позиция, поворот и размер |
| Shooting Target | Class-D, Sport, Binary | Тип мишени |

Объекты отображаются в Scene View через gizmo, поэтому их положение и размер
видны ещё до запуска игры.

## Как использовать

1. Откройте проект в Unity `2021.3.17f1`.
2. Выберите корневой объект схематика или одну из его дочерних групп.
3. Добавьте нужный объект через `GameObject → MER Objects`.
4. Настройте компонент в Inspector.
5. Нажмите `F6`, чтобы собрать схематик.

## Совместимость

Двери и мишени требуют сборку ProjectMER от Mango с поддержкой новых типов
блоков. Остальные типы сохраняют прежние числовые идентификаторы, поэтому старые
схематики продолжают работать.

| BlockType | ID |
| --- | ---: |
| Text | 8 |
| Interactable | 9 |
| Waypoint | 10 |
| Door | 11 |
| ShootingTarget | 12 |
